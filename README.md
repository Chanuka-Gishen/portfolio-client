# Developer Portfolio — Foundation

Next.js App Router + TypeScript + Tailwind CSS v4 with accessible light/dark themes.

## Start

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Customize

- `src/config/site.ts`: Your profile name and links.
- `src/app/globals.css`: Theme tokens.
- `src/app/page.tsx`: Homepage content (sections are placeholders).
- `src/app/layout.tsx`: Metadata and shared layout.

## Verify

```bash
npm run lint
npm run build
```

Live GitHub statistics, real project case-study pages and section content are intentionally left for subsequent phases. Replace generic links before publication.
